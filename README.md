# Homebrew tap for Perch

[Perch](https://github.com/anaydas/perch) is a free, open-source shelf for screenshots, text and files in the Mac notch.

## Install

```bash
brew install --cask anaydas/perch/perch
```

Needs macOS 13 or later. Works on Intel and Apple silicon Macs.

## Update

```bash
brew upgrade --cask perch
```

## Uninstall

```bash
brew uninstall --cask perch
```

To also remove Perch's saved items and settings:

```bash
brew uninstall --cask --zap perch
```
